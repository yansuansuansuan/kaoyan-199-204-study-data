## 数据更新约定

1. 开始训练前优先读取 `data/state.json`，检查到期错题/词汇。
2. **所有已完成的题都要归档**，包括做对、做错、误触作废和概念检查，逐题保留题源、答案、解题思路、耗时和批改。答案对但理由错，也记录薄弱点。英语阅读、作文和数学逻辑均适用。单词主动回忆/复习也记录每次真实表现。
3. 用户说「摸鱼刷题」：优先到期复习，短题1～2道，先作答后批改。
4. 用户说「晚上开始」：默认90分钟，短休息，一次一个任务，四模块均衡覆盖。
5. 每个短训练单元结束或切换科目时及时将已完成题写入月度档案，避免长对话导致遗失；用户说「今天结束」时补齐未保存记录，合并增量、**写入远端再回读校验**，并安排明日任务。需要更强保障时可按题同步，但可能增加授权弹窗。
6. 用户说「每周复盘」：根据真实练习和限时模考统计，输出最新台账及下一周优先级。
7. 复习按次日、3天后、7天后起步，按表现调整；仅看懂解析不算掌握，必须独立完成新同类题。
8. 如 GitHub 访问、写入或校验失败，明说“未同步”，提供完整增量，不能假装成功。
9. 多对话同时写入时先读最新SHA，遇冲突重新读取、按稳定ID合并，不能覆盖彼此新增记录。
