### 一、 学习目的与方法
*   **核心目标**：将“文字语言”转化为“符号语言”。做题时只需识别中文对应的逻辑符号即可，无需死记硬背充分/必要条件的定义。
*   **记忆方法**：坚持一周，每晚花10分钟进行“默写”训练（即看到中文能反应出对应符号）。

### 二、 基础假言命题刻画（第一组）
1.  **如果 S，那么 P** / **只要 S，就 P**
    *   符号：**S → P** （前推后）
    *   注：在管综逻辑中，这两者完全等价。
2.  **因为 S，所以 P** / **S 必然导致 P**
    *   符号：**S → P**
    *   注：因果关系需慎重，但此处姑且按条件关系处理。
3.  **S 是 P 的必要条件** / **S 必须 P**
    *   符号：**S → P**
    *   易错点：很多同学误以为是后推前，实际是前推后。（高频考点：2021管综考3次，2022金综1次，2023精综1次）
4.  **所有 S 都是 P**
    *   符号：**S → P**
    *   注：虽属直言命题，但写成假言形式不影响做题。
5.  **只有 S，才 P**
    *   口诀：**“才优先”**
    *   符号：**P → S** （“才”后面的内容放前面）
6.  **除非 S，否则 P**
    *   口诀：**“非保留，否则当箭头”**
    *   符号：**¬S → P**

### 三、 变化与复合结构刻画（第二组）
1.  **若要 S，必须 P**
    *   符号：**S → P**
2.  **所有 S 都不是 P**
    *   符号：**S → ¬P**
3.  **S 是 P 的基础 / 前提 / 必要条件**
    *   记忆法：**画房子**（基础在下，上层推下层）
    *   符号：**P → S**
    *   例：“认识世界是改造世界的基础” → 改造世界 → 认识世界
4.  **S 是 P 的唯一前提 / 当且仅当**
    *   性质：充要条件
    *   符号：**S ↔ P** （两头推）
5.  **用 S 就不会没有 P**
    *   解析：双重否定表肯定
    *   符号：**S → P**
6.  **只要有 S，就不会有 P**
    *   符号：**S → ¬P**

### 四、 进阶变化与逻辑定律（第三组）
1.  **如果没有 S，就不会有 P**
    *   符号：**¬S → ¬P**
    *   等价变换（逆否命题）：**P → S**
    *   原理：原命题与逆否命题等价。
2.  **只有 ¬S，才有 P**
    *   符号：**P → ¬S**
3.  **要想有 R，S 和 P 缺一不可**
    *   符号：**R → (S ∧ P)**
4.  **要想有 R，S 和 P 至少有一个**
    *   符号：**R → (S ∨ P)**
5.  **S 和 P 不可都有 / 不可兼得**
    *   符号：**¬(S ∧ P)**
    *   化简（德摩根定律）：**¬S ∨ ¬P**
    *   注意：这允许两者都不选，不同于异或（二选一）。

### 五、 “除非...否则...”的特殊情况与省略还原
*   **背景**：近十年真题出现频率降低（最后一次2013年），但小概率事件发生即为100%，仍需掌握。在职考生若实在记不住可跳过，影响较小。

1.  **除非 S，否则不 P**
    *   符号：**¬S → ¬P**
    *   等价（逆否）：**P → S**
2.  **除非没 S，否则一定有 P**
    *   符号：**S → P** （双重否定抵消）
3.  **省略形式的还原原则**：先补全“除非...否则...”再刻画。
    *   **例1：P，除非 S**
        *   还原：除非 S，否则 ¬P
        *   符号：**¬S → ¬P** ⇔ **P → S**
    *   **例2：有 P，否则无 S** （2013年真题原型）
        *   还原：除非有 P，否则无 S
        *   符号：**¬P → ¬S** ⇔ **S → P**
    *   **例3：S 和 P 至少有一个，除非 Q**
        *   还原：除非 Q，否则 (S ∨ P)
        *   符号：**¬Q → (S ∨ P)**
        *   注意：这里的“非”不能丢。
4.  **“除非”与其他词连用的弱化规则**：
    *   若“除非”与“只有/才”或“如果/那么”直接粘连，**去掉“除非”及其后的否定**，按常规句式处理。
    *   **例1：除非 S，才 P**
        *   处理：视为“只有 S，才 P”
        *   符号：**P → S** （不要 ¬S）
    *   **例2：若要 S，除非 P**
        *   处理：视为“如果 S，那么 P”
        *   符号：**S → P** （不要 ¬P）
    *   **真题案例**：“若要人不知，除非己莫为”
        *   符号：**人不知 → 己莫为**
