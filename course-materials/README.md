# 考研课程资料 / Course Materials

此文件夹为199管理类综合能力、204英语（二）的辅助课程资料入口。主要用于放置**个人整理的知识点笔记、课程目录、索引、可核查的解题方法和学习摘记**，与 `data/state.json` 的个人答题台账分开。

建议资料分层分类（按需创建，不必一次完成）：
- `199-math/` 数学
- `199-logic/` 逻辑
- `199-writing/` 写作
- `204-english/` 英语二
- `index/` 原课程文件清单、来源与处理进度

为了跨对话可读，建议每个笔记保留：课程或讲义名、章节、视频时间戳或页码、知识点、例题标识与个人总结。录音/视频可存于自己的网盘，笔记中记录原视频文件名与网盘位置。

## 上传权限规则

**本仓库目前为公开仓库。**

- ✅ **允许上传**：已确认具备公开发布权限的课程资料，包括完整视频文稿（含原始时间戳）、讲义索引与自有整理笔记。仓库所有者已于 2026-10-27 明确确认，本项目所收录的 27 考研 199/204 课程资料具备公开发布授权。
- ❌ **不得上传**：未获授权的第三方资料、他人付费课程、访问口令、账号凭据，以及任何与学习无关的个人敏感信息。
- ⚠️ **视频本体不入库**：原始 mp4/flv 体积过大，保存在个人网盘；仓库只存文稿、索引与笔记，并记录原视频文件名与网盘位置。

新增资料若来源存疑，先确认授权，再上传。

**已有学习主数据请勿改动：** `data/state.json`、`data/attempts/`、`AGENTS.md`。这些是不同学习对话共用的真实答题和教学规则数据。
