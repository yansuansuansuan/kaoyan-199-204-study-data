# 考研课程资料 / Course Materials

此文件夹为199管理类综合能力、204英语（二）的辅助课程资料入口。主要用于放置**个人整理的知识点笔记、课程目录、索引、可核查的解题方法和学习摘记**，与 `data/state.json` 的个人答题台账分开。

建议资料分层分类（按需创建，不必一次完成）：
- `199-math/` 数学
- `199-logic/` 逻辑
- `199-writing/` 写作
- `204-english/` 英语二
- `index/` 原课程文件清单、来源与处理进度

为了跨对话可读，建议每个笔记保留：课程或讲义名、章节、视频时间戳或页码、知识点、例题标识与个人总结。录音/视频可存于自己的网盘，笔记中记录原视频的文件名与时间位置。

**注意：本仓库目前为公开仓库。** 不要直接上传未获公开发布许可的付费课程视频、整份讲义、完整转录文字、访问口令等材料；宜只上传允许公开的材料和你自己整理的简要知识笔记。GitHub 普通仓库也不适合保存大量大体积视频。

**已有学习主数据请勿改动：** `data/state.json`、`data/attempts/`、`AGENTS.md`。这些是不同学习对话共用的真实答题和教学规则数据。
